# Проверка архитектурного пакета

Дата: 16 сентября 2026. Проверяется **проект и его артефакты**, а не ещё не реализованный EmSim.

## Выполнено

- Прочитаны 26 требований исходного `additional_requirements.md`; проверено соответствие 26 уникальным строкам AR-01…26 без пропусков/дубликатов.
- Рассмотрены ТЗ, обе DDD-схемы, предметные правила памятки и структура XLSX-классификатора. Визуально проверены ключевые страницы памятки с карточкой и статусами.
- Core исследован по domain/application/worker/queue/postgres/inference/HTTP/SQL/config; важные выводы привязаны к конкретным файлам в `02-core-reuse.md`.
- Для 107 локальных исходных файлов записаны SHA-256; повторное сравнение подтвердило неизменность источников в ходе подготовки пакета. Продуктовый код core не изменялся.
- Шесть Graphviz схем собраны в SVG и PNG, SVG успешно разобраны XML-парсером; схемы визуально просмотрены.
- Автономный HTML-атлас проверен headless Chrome при ширине 1440px и 390px: все шесть tabs переключаются, отображается ровно одна панель, keyboard arrows работают, JS exceptions нет, внешних HTTP(S) запросов нет. Графы встроены в HTML; на узком экране схема имеет собственную горизонтальную прокрутку/ссылку на SVG.
- Проверены локальные ссылки HTML и Markdown. Редактируемые Mermaid-исходники собраны также в `08-uml.md`; независимый Mermaid parser в этой среде не запускался. Готовое визуальное представление атласа использует проверенные SVG и от Mermaid runtime не зависит.
- `gofmt` и `go test docs/architecture/contracts/types.go` успешно компилируют Go-эскиз (`[no test files]`). Это проверка согласованности объявлений, не тест реализации бизнес-логики.
- В проекте явно разделены предметные ошибки, технические сбои, стоп преподавателя, сохранность ACK и неподтверждённые/offline данные. Race-инварианты описаны на транзакционных границах.

## Не заявлено как выполненное

- Реализация API, БД, UI, VoIP, inference, HA или deployment EmSim.
- Запуск regression/integration suite исходного core, тесты миграций будущего продукта.
- Достижение 2с / 20 сессий / 150мс / 100 writes/s / 30с reports на целевом оборудовании.
- Подтверждение качества AI, production restore, compliance/certification.

Эти проверки перечислены как release gates в `06-delivery-and-validation.md`, а не заменены заявлением об архитектурном покрытии.

## Повторная генерация

`python3 tools/build_atlas.py` из каталога пакета требует Graphviz `dot`; обновляет DOT/SVG/PNG, автономный HTML и сборный UML-документ. Исходные `.mmd` редактируются напрямую. `tools/verify_atlas.cjs` содержит пути локального окружения автора; для запуска на другом компьютере указать свой Playwright/Chrome. Эти инструменты относятся к документации, не к архитектуре runtime продукта.
