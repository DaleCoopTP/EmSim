Воспроизводимость

Идемпотентность

Локальный control plane и отдельный media plane

Все сетевые hop защищены. Базовое приложение не требует GPU; inference масштабируется отдельно. Для отказа узла нужен HA-профиль, одного Compose недостаточно.
