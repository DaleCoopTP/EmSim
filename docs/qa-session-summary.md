## Следствия для архитектуры

1. `card_workflow` — единственное обязательное ядро. `call_card` (CallerSimulator, диалог, входящая речь, disclosure) — bonus.
2. Голос = TTS исходящего звонка (+ опционально STT для записи сказанного в evidence). Asterisk/WebRTC/media gateway/barge-in/chunks — не нужны.
3. Генерация карточек — офлайн до занятия из билетов; judge — после submit. Real-time LLM в цикле обучаемого не нужен → риск CPU-inference снят.
4. Тайминги: 30 с открыть, 3 мин отработать.
5. Добавить: назначение заданий по рабочим местам; адаптивная рекомендация уровня; номер рабочего места в отчёте; накопление правок преподавателя как размеченных примеров.
6. Нагрузка: 10 одновременных без падений, 20–30 в классе. HA/fencing — только в документацию.
7. UI: копия карточки из памятки, минимум самодеятельности.
