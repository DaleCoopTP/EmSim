# Референс интерфейса Системы-112 (инструкция оператора 112, версия 2.1)

Источник: «Инструкция по заведению карточки 2507ГСИ.docx» (выдана заказчиком 17.09.2026). Это инструкция **оператора 112**. В EmSim она — основа вёрстки обоих рабочих мест (оператор 112 и диспетчер ДДС), полей карточки, опросных карт и окна оповещения служб. Все снимки — в `112-instruction/`.

Дополнительно заказчик предоставил два отдельных снимка профильных карт:
[опросная карта 104](112-3-profile-104.png) и
[опросная карта 101](112-3-profile-101.png). По ним собран каталог 112
(`seed/intake-catalog.json`, описание — [seed/README.md](../../seed/README.md)).

## Что берём

- Визуальный стиль: тёмно-серые панели, оранжевые акценты (кнопки «сохранить», список служб), светло-серые формы, Roboto; таймер «минут : секунд» в правом верхнем углу; шапка «Происшествие N · Зарег дата · Опер., АРМ N, ФИО».
- Вход: логин, пароль, **номер АРМ** — ровно наша модель (`workstation_no` при логине).
- Блоки карточки: телефоны (АОН / предоставленный / телефон на место), ФИО заявителя + статус (очевидец, пострадавший, родственник, знакомый, ребёнок, участник), канал связи, пострадавшие Нет/Есть + число, адрес (страна, субъект, нас. пункт, объект, округ, район, улица, дом, корпус, стр., кв., подъезд, этаж, код, описательный адрес), тип происшествия + опросная карта (кнопки-признаки), «Описание со слов заявителя» (≤ 1999; в 03 уходят первые 100), панель служб внизу (основные — двойное подчёркивание).
- **Отработка** (Рис. 69–74): запись о звонке — Служба / Куда звонили / Телефон / Кто принял / Суть сообщения. В EmSim звонок обучаемого завершается заполнением «Кто принял» и «Суть сообщения» — детерминированно проверяемые поля.
- Статус службы в карточке обновляется автоматически, история статусов — по стрелке над названием службы (Рис. 67); 48 ч без «Завершение работ» → карточка «Не завершено».
- «Совпадение» по телефону/адресу и привязка карточек (Рис. 49–55) — механика дублей.
- Аудит (Рис. 93): таблица Карточка / Опер. / ФИО / Дата / Время / Событие — референс для нашего монитора и журнала действий.
- Горячие клавиши: Alt+S сохранить/отработана, Esc закрыть, Alt+A адрес, Alt+T тип, Alt+O отработки, Alt+Z службы.

## Что не берём

Телефония Avaya, перевод вызова и конференция, карта (Яндекс/ФИАС), СМС, напоминания, «важное происшествие», сообщение об ошибке. Эти элементы показаны в интерфейсе неактивными или не показаны; перевод и конференция с ДДС запланированы отдельно.
