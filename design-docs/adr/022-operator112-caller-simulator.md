# ADR-022. Контракт симулятора заявителя для 112

Статус: accepted · 2026-09-23

## Контекст

В 112-1 `answer_incoming` сразу выдаёт весь линейный текст. Для уточняющего
опроса ответ должен зависеть от выбранного вопроса, а телефонное соединение
должно оставаться самостоятельным состоянием. Поздний ИИ-адаптер из 112-8
не должен менять протокол команд и формат evidence.

## Решение

- Отдельный порт `CallerSimulator` принимает снимок диалога и выбранный ID
  вопроса, возвращает готовые реплики и ID раскрытых фактов. Реализация
  112-2 детерминирована и работает локально без фоновой задачи.
- Сценарий определяет авторские ID и текст реплик. Состояние занятия
  фиксирует фактически произнесённые реплики, авторов, время сервера,
  команду-источник и ID вызова. История не пересоздаётся из сценария.
- Телефонные команды решают, можно ли говорить сейчас. Симулятор отвечает
  только за содержание и доступность подготовленных вопросов.
- Утверждённый сценарий и скрытые факты доступны симулятору и преподавателю.
  Обучаемому выдаются только уже произнесённые реплики и текущие вопросы.
- В 112-8 вычисление модели должно идти вне транзакции команды, после чего
  результат принимается с проверкой актуальности вызова и версии хода.
  Этот ADR не разрешает интерактивную модель и не меняет ADR-003.

## Последствия

Старый `call.script` сохраняется для ранее утверждённых сценариев. Новые
сценарии используют `intake112.dialogue`. ДДС не использует этот порт.
